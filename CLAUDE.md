# CLAUDE.md

Read [`AGENTS.md`](AGENTS.md).

It is deliberately the same file Codex and every other contributor reads. Two
instruction files that say slightly different things is how two agents end up
building in different directions, which is the exact problem these documents
exist to prevent. Put anything you would have written here in `AGENTS.md`
instead.

Note that `client/CLAUDE.md` is a **different** file: it is Zotero's own,
covering the desktop client's build system and code style, and it applies when
working inside `client/`.
